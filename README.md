FlightSearchApp
  A modern Android flight search application built with Kotlin and Jetpack Compose. The app demonstrates clean separation of UI, business logic, and data       handling   using MVVM architecture, with Room for local data persistence and Retrofit for network communication.
  
Overview
  FlightSearchApp allows users to search for available flights and view flight-related information through a modern Compose-based interface.
  The project was built to practice and demonstrate real-world Android development concepts includin
    - Jetpack Compose UI development
    - MVVM architecture
    - Room Database
    - Repository pattern
    - ViewModel and UI state management
    - Kotlin Coroutines
    - Local data persistence
    
Features
  - Search for flights
  - Display flight search results
  - Modern Jetpack Compose UI
  - Retrieve data using Retrofit
  - Store and retrieve local data using Room
  - Manage UI state through ViewModel
  - Repository-based data layer
  - Asynchronous operations using Kotlin Coroutines
  - Compose Navigation
    
Tech Stack
  Kotlin	Primary programming language
  Jetpack Compose	UI development
  MVVM	Application architecture
  Room	Local database
  Kotlin Coroutines	Asynchronous programming
  Flow / StateFlow	Reactive state handling
